# Design Brief Maker

흩어진 디자인 요청사항을 구조화하여 실무용 디자인 브리프로 자동 변환하는 업무용 SaaS 웹앱입니다.

## 주요 기능

- **프로젝트 생성** — 대시보드/브리프 목록/템플릿에서 새 디자인 브리프를 즉시 시작
- **구조화된 디자인 요청 입력** — 5단계 위저드(기본정보 → 콘텐츠 → 스타일 → 참고자료 → AI 브리프)
- **필수 항목 검증** — 단계별 필수 입력값 검증 및 이해하기 쉬운 한글 오류 메시지
- **AI 디자인 브리프 생성** — 입력값을 분석해 프로젝트 개요, 디자인 방향, 레이아웃·컬러·타이포그래피 제안, 검색 키워드, 체크리스트를 자동 생성
- **브리프 직접 수정** — 생성된 브리프를 화면에서 바로 편집
- **프로젝트 저장** — 모든 입력값과 브리프는 브라우저 로컬 저장소에 자동 저장
- **PDF 출력** — 완성된 브리프를 PDF 파일로 다운로드 (공유/복사 기능 포함)

## 개발 스택

- React + TypeScript + Vite
- Tailwind CSS v4
- Zustand (localStorage persistence)
- jsPDF + html2canvas-pro (PDF export)

## 실행 방법

```bash
npm install
npm run dev       # 개발 서버 실행
npm run build     # 프로덕션 빌드
```
